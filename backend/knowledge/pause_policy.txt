SUBCLARITY SUBSCRIPTION POLICY

Topic: Pause Subscription

Definition:
Pause temporarily suspends an active subscription without permanently cancelling it.

Important distinction:
Pause is not cancellation.

When a subscription is paused:
- User temporarily stops active usage.
- Subscription remains associated with the user's account.
- Future billing depends on the selected pause duration.
- User can resume the subscription later.

Before confirmation:
The user must see:
- Current plan
- Current billing cycle
- Next billing date
- Difference between pause and cancellation

The system must never automatically pause a subscription without user confirmation.
